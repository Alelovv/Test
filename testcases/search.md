Тест-кейс: поиск вакансий на hh.ru

1
Название: Поиск по ключевому слову
Ввод: ввести «Python» в строку поиска, нажать «Найти»
Ожидаемый результат: открывается список вакансий по запросу «Python»

2
Название: Поиск по профессии на русском языке
Ввод: ввести «тестировщик», нажать «Найти»
Ожидаемый результат: отображается список вакансий для тестировщиков

3
Название: Запуск поиска клавишей Enter
Ввод: ввести «аналитик», нажать Enter
Ожидаемый результат: поиск запускается, открывается список вакансий

4
Название: Поиск с пустой строкой
Ввод: оставить строку пустой, нажать «Найти»
Ожидаемый результат: сайт не выдаёт ошибку, открывается общий список вакансий или остаётся главная страница

5
Название: Поиск по несуществующему запросу
Ввод: ввести «фыфыфыфы12345», нажать «Найти»
Ожидаемый результат: показывается сообщение, что ничего не найдено

6
Название: Поиск со спецсимволами
Ввод: ввести «!@#$%^&*()», нажать «Найти»
Ожидаемый результат: нет ошибки сервера, показывается пустой результат или сообщение «ничего не найдено»

7
Название: Поиск с очень длинной строкой
Ввод: вставить текст длиной более 500 символов, нажать «Найти»
Ожидаемый результат: сайт не зависает, показывает результат или сообщение «ничего не найдено»

8
Название: Лишние пробелы в запросе
Ввод: ввести «  Java  » (с пробелами по краям), нажать «Найти»
Ожидаемый результат: пробелы игнорируются, результаты такие же, как для «Java»

9
Название: Регистр букв в запросе
Ввод: найти «PYTHON», затем найти «python»
Ожидаемый результат: результаты поиска совпадают

10
Название: Фильтр по региону
Ввод: найти «менеджер», в фильтрах выбрать регион «Владивосток»
Ожидаемый результат: в списке только вакансии выбранного региона

11
Название: Открытие вакансии из результатов
Ввод: найти «Python», нажать на название первой вакансии
Ожидаемый результат: открывается страница вакансии с описанием и требованиями

12
Название: Переход на следующую страницу результатов
Ввод: найти «менеджер», внизу страницы нажать на номер следующей страницы
Ожидаемый результат: открывается вторая страница с другими вакансиями
Название: Переход на следующую страницу результатов
Ввод: найти «менеджер», внизу страницы нажать на номер следующей страницы
Ожидаемый результат: открывается вторая страница с другими вакансиями
