# Проверка футера hh.ru

Проверка нижней части главной страницы hh.ru во Владивостоке: видны ли ссылки на компьютере и узком экране, куда они ведут и что меняется при выборе English.

**Результат:** из 13 проверок 11 прошли. Два замечания:

1. В футере после переключения на English две ссылки остаются на русском: «Рейтинг работодателей России» и «Пользовательское соглашение». Нужно уточнить, предусмотрен ли для них перевод.
2. Ссылка «Требования к ПО» открывает нужную страницу, но в инструкции на ней есть опечатка: «Goolge Chrome» вместо «Google Chrome».
